# Host certification

A host is supported only when this directory contains a passing certificate for
that host and operating system. Standards compatibility is not certification.

See [SUPPORT.md](SUPPORT.md) for the current matrix and
[manual-procedure.md](manual-procedure.md) for the recorded evidence procedure.

Certificates contain package versions, host versions, operating systems, and
limitations. They must not contain credentials, private prompts, tokens, or
machine-specific secrets.
