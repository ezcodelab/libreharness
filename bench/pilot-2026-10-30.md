# Pilot benchmark, 2026-10-30

Status: **pilot only. Not the full Terminal-Bench result and not a public
claim.**

Dataset: `terminal-bench@2.0`, commit recorded by Harbor in each job.
Model: `ollama-cloud/deepseek-v4.1-flash` through
`https://ollama.com/v1` with the OpenAI Chat Completions adapter.
Harness: `harbor_agent.opencode_agent:OpenCodeLibreHarness`.
Baseline: stock `opencode` agent.
Repetitions: 1 per task. Two completed tasks per arm. One further task was
cancelled by the operator's 30-minute shell timeout and is excluded.

## Results

| Task | Arm | Reward | Cost USD | Input tokens | Output tokens | Agent wall |
|---|---|---:|---:|---:|---:|---:|
| gpt2-codegolf | harness | 1.0 | 0.0846 | 4,927,498 | 80,542 | 10m 52s |
| gpt2-codegolf | plain | 1.0 | 0.0906 | 4,688,554 | 66,621 | 9m 18s |
| break-filter-js-from-html | harness | 1.0 | 0.0033 | 48,678 | 2,784 | 16s |
| break-filter-js-from-html | plain | 1.0 | 0.0054 | 133,625 | 5,038 | 62s |

Headline for this pilot: **pass@1 2/2 (100%) for both arms.** There is no
measured quality delta on these two tasks.

## Operational notes

- The harness arm completed both trials with no exception.
- The plain arm passed both verifiers but recorded a post-completion
  `ApiRateLimitError` on gpt2-codegolf and a `NonZeroAgentExitCodeError` on
  break-filter-js-from-html. Both verifier rewards were 1.0.
- The harness adapter used fewer input tokens on break-filter and slightly fewer
  dollars, but more input tokens on gpt2. Do not generalize from two tasks.
- The third task, `llm-inference-batching-scheduler`, was cancelled by the
  outer 30-minute timeout before it could finish. It is not a failure of the
  harness.

## What this does and does not show

It shows the Harbor adapter can install LibreHarness in the sandbox, call the
model through the configured Ollama endpoint, complete a task, and produce a
verifiable reward in two different task types.

It does not show a harness quality advantage. Two tasks, one repetition, and one
model cannot support that claim. A full Terminal-Bench run needs many more
tasks, n=3, a plain baseline on exactly the same tasks, and the raw run data.

## Reproduction

```sh
export OLLAMA_API_KEY=...
PYTHONPATH="$PWD" harbor run \
  -d terminal-bench@2.0 \
  -a harbor_agent.opencode_agent:OpenCodeLibreHarness \
  -m ollama-cloud/deepseek-v4.1-flash \
  --base-url https://ollama.com/v1 \
  --api-key-name OLLAMA_API_KEY \
  --api-format openai_chat_completions \
  -l 1 -k 1
```

The jobs are under `jobs/` locally and are ignored by git.
