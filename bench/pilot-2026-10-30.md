# Pilot benchmark, 2026-10-30

Status: **invalid as a harness comparison. Adapter smoke only. Not the full
Terminal-Bench result and not a public claim.**

> **Correction, 2026-10-31.** The adapter's `configure()` method was dead code:
> Harbor 0.25.0 calls `setup()`, not `configure()`. The overlay (`AGENTS.md`,
> agents, commands, skills, and queue) was never uploaded. The rows below are
> therefore **adapter-only** runs: stock OpenCode plus the adapter's run
> wrapper. They are not LibreHarness results. Keep them as evidence that the
> adapter could install OpenCode, authenticate, and finish a task; do not cite
> them as a harness quality result. The `setup()` fix and the install-only
> proof are in `harbor_agent/README.md`.

Dataset: `terminal-bench@2.0`, commit recorded by Harbor in each job.
Model: `ollama-cloud/deepseek-v4.1-flash` through
`https://ollama.com/v1` with the OpenAI Chat Completions adapter.
Adapter: `harbor_agent.opencode_agent:OpenCodeLibreHarness` (overlay not
uploaded in this pilot; see the correction).
Baseline: stock `opencode` agent.
Repetitions: 1 per task. Two completed tasks per arm. One further task was
cancelled by the operator's 30-minute shell timeout and is excluded.

Headline for this pilot: **pass@1 2/2 (100%) for adapter-only and plain.** There
is no measured quality delta, and no harness result.

## Operational notes

- The adapter-only arm completed both trials with no exception.
- The plain arm passed both verifiers but recorded a post-completion
  `ApiRateLimitError` on gpt2-codegolf and a `NonZeroAgentExitCodeError` on
  break-filter-js-from-html. Both verifier rewards were 1.0.
- The adapter-only arm used fewer input tokens on break-filter and slightly
  fewer dollars, but more input tokens on gpt2. Do not generalize from two
  tasks, and do not attribute the difference to the harness overlay.
- The third task, `llm-inference-batching-scheduler`, was cancelled by the
  outer 30-minute timeout before it could finish. It is not a failure of the
  harness.

## What this does and does not show

It shows the Harbor adapter can install OpenCode in the sandbox, authenticate
through the configured Ollama endpoint, complete a task, and produce a
verifiable reward in two task types.

It does not show that LibreHarness ran, because the overlay upload was dead
code in this pilot. It also does not show a harness quality advantage. Two
tasks, one repetition, and one model cannot support that claim. A full
Terminal-Bench run needs the `setup()` overlay fix, a fresh smoke, many more
tasks, n=3, a plain baseline on exactly the same tasks, and the raw run data.

## Post-fix one-task smoke, 2026-10-31

After the `setup()` overlay fix, the same `break-filter-js-from-html` task was
run once per arm with OpenCode 1.19.5 and the same model.

| Arm | Reward | Exception | Cost USD | Input tokens | Output tokens | Wall |
|---|---|---:|---|---:|---:|---:|---:|
| LibreHarness adapter | 1.0 | none | 0.0215 | 519,812 | 17,997 | 4m 14s |
| plain OpenCode | 1.0 | `NonZeroAgentExitCodeError` | 0.0058 | 71,875 | 5,815 | 2m 43s |

The adapter trial log shows the overlay `mkdir` after OpenCode 1.19.5 installs.
Its `opencode.txt` still starts with the EPIPE trace, but the guard tolerates it
because the stream also contains a completed `step_finish` with `reason: "stop"`.
The trial completed with no exception. The plain arm passed the verifier but
recorded the EPIPE false failure.

This is one task and one repetition. It shows the adapter fix works and removes
the false failure. It does not show a quality advantage; on this task the plain
arm was faster and cheaper. A comparison still needs the same task set, n=3, and
the raw data.

## Reproduction

The command below requires the `setup()` overlay fix. The original pilot ran
before it, so it is not a reproduction of the harness arm.

```sh
export OLLAMA_API_KEY=...
PYTHONPATH="$PWD" harbor run \
  -d terminal-bench@2.0 \
  -a harbor_agent.opencode_agent:OpenCodeLibreHarness \
  -m ollama-cloud/deepseek-v4.1-flash \
  --base-url https://ollama.com/v1 \
  --api-key-name OLLAMA_API_KEY \
  --api-format openai_chat_completions \
  --ak version=1.19.5 \
  -l 1 -k 1
```

The jobs are under `jobs/` locally and are ignored by git.
