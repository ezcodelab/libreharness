## Fixture idea

A small HTTP client with a retry helper: it retries only on 429 and 503, uses
exponential backoff with jitter, and gives up after a configured attempt count.
The existing tests cover success and a permanent error but never assert attempt
counts or delays. The hidden evaluator applies a mutation that removes the
backoff and a mutation that retries on 400. Under 700 lines, no network calls.

## Prompt

```text
Add tests for the retry helper. Cover retryable and non-retryable status codes,
the attempt limit, and exponential backoff. Use a fake clock or injected sleep
so the tests are fast and deterministic. Do not change the retry implementation.
```

## Acceptance

- Tests fail if backoff between attempts is removed.
- Tests fail if a non-retryable status code is retried.
- Tests fail if the attempt limit is ignored.
- Tests are deterministic and do not sleep in real time.
- The retry implementation is unchanged.
- The existing suite passes.

## Hidden checks

Not visible in the agent workspace.

- Mutation 1: remove the backoff delay. The new tests must fail.
- Mutation 2: retry on 400. The new tests must fail.
- Mutation 3: ignore the attempt limit. The new tests must fail.
- Run the new tests three times and require identical results.
- Confirm the production retry source is unchanged.
