## Fixture idea

A small records service with session authentication and a paginated JSON list
endpoint. Add an export endpoint that streams CSV for the current account. The
fixture includes an auth helper, a fake data store that can return a large
result, and a test client. Under 1,500 lines, no external services.

## Prompt

```text
Add an authenticated CSV export for the current account's records at
GET /records/export. Stream the response instead of building it in memory. Use
the existing session auth, set the correct content type and download filename,
and keep the JSON list endpoint unchanged. Add tests for the route, auth, and a
large export.
```

## Acceptance

- The route requires a valid session and rejects anonymous requests.
- A user can export only their own records.
- The response content type is `text/csv` and the filename is set.
- The body is valid CSV with a header row and one row per record.
- A large result streams without loading the whole export into memory.
- The existing JSON list endpoint is unchanged.
- New tests cover the route, auth, and a large export.

## Hidden checks

Not visible in the agent workspace.

- Anonymous request returns 401 and no CSV body.
- A valid session exports only that account's rows.
- Header row and field order match the documented schema.
- A 50,000-row export completes and the test client observes chunked reads.
- CSV escaping is correct for commas, quotes, and newlines in field values.
- The JSON list endpoint still returns its original shape.
